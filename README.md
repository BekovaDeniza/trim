# trim

Небольшая Python CLI-утилита для удаления пробелов и табуляции в конце строк.

## Установка

```bash
pip install trim
```

## Использование

Обработать файлы:

```bash
trim file.py main.py
```

Обработать директорию:

```bash
trim src/
```

Обрабатывать рекурсивно:

```bash
trim --recursive src/
```

Обрабатывать только файлы определённого типа:

```bash
trim --type .py,.pyi src/
```

Комбинировать параметры:

```bash
trim --recursive --type .py,.pyi src/
```

## Что делает

Удаляет пробелы и табуляцию в конце строк, включая строки, состоящие только из whitespace.

**До:**

```text
def hello():··
····
    print("Hello")··
```

**После:**

```text
def hello():

    print("Hello")
```

Остальное содержимое файлов не изменяется.

## Возможности

* файлы и директории;
* рекурсивный обход;
* фильтрация по расширению;
* минимальное изменение содержимого.
